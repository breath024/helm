# 2026-08-14 (2) — 컨텍스트 사용량 바 (본체)

## 고친 것
- **상단바에 컨텍스트 사용량 바 추가** (`app.py` + `static/`). 지금 보고 있는 세션이
  물고 있는 토큰을 막대 + `48.3% · 96,679 / 200,000`로 보여준다. 70%부터 노랑, 90%부터 빨강.
- 서버 `/api/usage` 신설. CLI가 토큰 수를 밖으로 안 내주므로 **세션 jsonl의 마지막
  assistant `usage`**를 읽어 계산한다: `input + cache_read + cache_creation + output`.
- 패널 ↔ 세션파일 짝짓기(`_session_file`): 새 세션은 ID를 미리 알 수 없어 **패널이 뜬 뒤에
  갱신된 파일 중 최신**으로 찾고, 한 번 찾으면 붙잡아 둔다(같은 폴더의 다른 패널이 못 가져감).
  이어받기(`--resume`) 세션은 아직 안 썼으면 그 파일을 그대로 읽는다.

## 알게 된 것
- 서브에이전트 응답은 `isSidechain: true`로 표시된다 → **본 대화 컨텍스트가 아니라서 걸러낸다.**
  안 거르면 서브에이전트 usage가 튀어 숫자가 요동친다.
- 세션 jsonl은 **첫 메시지를 보내기 전까지 안 만들어진다**. 새 세션을 열고 아무것도 안 치면
  잴 게 없어서 바가 숨는다(고장 아님).
- 압축(compact) 처리는 따로 필요 없다 — 압축 뒤 응답의 usage가 알아서 작아진다.
- 모델 id가 `claude-haiku-4-5-20251001`처럼 날짜가 붙어 돌아온다. 한도는 지금 전부 200k라
  문제 없지만, 모델별 예외를 넣을 땐 `CONTEXT_LIMITS`에 날짜 붙은 id도 같이 넣어야 한다.

# 2026-08-14 (3) — 구독 한도 바 (/usage 긁기)

## 고친 것
- 상단바에 **구독 한도 알약** 추가: `5시간 12% · 주간 69%`, 툴팁에 리셋 시각·프로모·주의문구.
  클릭하면 즉시 새로고침. 서버는 10분마다 갱신(`/api/limits`).
- 5시간·주간 한도는 CLI가 **플래그로도 파일로도 안 준다** (`claude --help` 확인,
  서브커맨드에 usage 없음, `~/.claude`·`~/.claude.json`에도 수치 없음).
  그래서 **안 보이는 세션을 띄워 `/usage`만 치고 화면을 긁는다**. 모델 호출이 아니라
  계정 조회라 토큰 비용 0(패널의 Total cost가 $0.0000).

## 터진 것 / 알게 된 것
- **눈 감고 Enter 치는 위험** — 신뢰 안 된 폴더에서 긁으면 `/usage\r`의 그 Enter가
  "Yes, I trust this folder"를 눌러버린다. **테스트 중 임시폴더 하나를 실제로 신뢰 처리했다**
  (`%TEMP%\helm-usage-probe`, 빈 폴더). 지금은 버퍼에 신뢰 프롬프트가 보이면 **안 치고 포기**한다.
  긁는 폴더는 HELM 폴더(이미 신뢰됨)로 고정.
- **claude는 새로 뜰 때 남의 세션 파일 끝에 `bridge-session` 줄을 붙인다** → mtime이 갱신된다.
  한도 긁기 세션이 10분마다 뜨므로, mtime만 보고 패널↔세션파일을 짝지으면 **엉뚱한 파일을
  잡는다**. 이제 `_session_file()`은 *패널이 뜬 뒤 시각의 assistant 응답이 실제로 들어있는
  파일*만 잡는다(`_epoch()`로 timestamp 비교).
- 한도 수치는 claude가 스스로 "이 기기의 로컬 세션 기준 근사치"라고 밝힌다 —
  다른 기기·claude.ai 사용분은 안 들어간다. 툴팁에 그대로 적어뒀다.

## 확인한 것
- 실제 긁기 3회 — `5시간 39%/47%/12%`, `주간 67%→69%`, 리셋 시각이 5시간 창 리셋에 맞춰
  `10:10pm → 3:10am`으로 따라 바뀌는 것까지 확인
- playwright DOM — 서버가 긁어오면 알약이 실제로 붙고(`5시간 47% · 주간 68%`), 92%에서
  빨강 클래스로 바뀌고, 툴팁 문구·바 폭 정상, pageerror 0건
- mtime만 건드려진 파일을 패널이 안 잡는 것(가드) + 진짜 세션은 여전히 잡는 것(회귀) 둘 다 확인
